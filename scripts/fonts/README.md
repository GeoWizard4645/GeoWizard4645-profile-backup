# Embedded portrait font

`jbmono-ramp.woff2` is JetBrains Mono v2.304, subset to the thirteen
characters used by the ASCII portrait and embedded into the generated SVG as a
base64 data URI. Its 0.600 em advance keeps the character grid identical across
macOS, Windows, and Linux.
